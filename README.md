# Unicode Typer

한글·영문·특수문자를 다른 Windows 앱의 입력창에 한 글자씩 전송하는 프로그램입니다. 대상 앱에 클립보드 붙여넣기나 Ctrl+V를 사용하지 않고 Windows `SendInput` Unicode 키 이벤트를 전송합니다.

## 다운로드

[최신 버전 다운로드](https://github.com/KEYSTONE360/unicode-typer/releases/latest)

`UnicodeTyper.exe`를 내려받아 실행하십시오. 별도의 Python 설치는 필요하지 않습니다. Windows 10/11 x64용입니다.

## 사용 방법

1. 큰 입력란에 타이핑할 글을 붙여넣습니다.
2. **시작 대기(초)**와 **글자 간격(ms)**을 설정합니다.
3. 초록색 **타이핑 시작** 버튼을 누릅니다.
4. 대기시간 안에 다른 앱으로 이동해 입력할 위치를 클릭합니다.
5. 중단하려면 어느 창에서든 **F8**을 누릅니다. 빨간색 **즉시 중단** 버튼도 사용할 수 있습니다.

| 설정 | 범위 | 기본값 |
|---|---|---|
| 시작 전 대기 | 1~60초 | 5초 |
| 글자 사이 대기 | 1~5,000ms | 50ms |

1,000ms는 1초입니다. 느리게/보통/빠르게 버튼은 각각 150/50/10ms를 설정합니다. 설정은 다음 시작부터 적용되며, 표시되는 진행률은 전송한 글자 수를 뜻합니다. 대상 앱이 실제로 저장한 글자 수를 확인하는 기능은 없습니다.

## 동작과 호환 범위

- 한/영 전환 상태와 독립적으로 Unicode 글자를 전송합니다. 한글·영문·기호·이모지의 실제 표시는 대상 앱과 글꼴에 따릅니다.
- 물리 키보드의 한글 자모 조합 과정을 재현하는 방식은 아닙니다.
- 줄바꿈과 탭은 실제 Enter/Tab 키로 전송하므로 대상 앱에서 전송, 제출, 입력칸 이동 등이 실행될 수 있습니다.
- 입력 중 다른 최상위 창으로 전환하면 중단합니다. 같은 창 안에서 입력 위치를 바꾸는 동작은 감지하지 않습니다.
- Shift/Ctrl/Alt/Win 키를 누른 상태가 감지되면 중단합니다.
- 중단 후 시작하면 글의 처음부터 다시 입력합니다. 이미 입력한 글은 삭제하지 않습니다.
- 관리자 권한 앱에 입력하려면 같은 권한으로 실행해야 할 수 있습니다.
- 보안 입력창, 게임, 원시 키보드 이벤트만 처리하는 앱 등 합성 Unicode 키 입력을 차단하는 대상에서는 작동하지 않을 수 있습니다.
- 네트워크 통신이나 입력 내용 저장 기능은 없습니다.

## 검증 상태

개발 중 Windows 테스트 입력창에서 한글·영문·기호·이모지·줄바꿈 혼합 전송, F8 중단, 대기 중 취소를 확인했습니다. 최종 UI 변경 후 재검증에서는 입력창 포커스 확보에 실패한 사례가 있으며, 최종 EXE의 메모장 대상 검증은 사용자에 의해 중단되어 완료되지 않았습니다. 최종 EXE 실행과 버튼 배치는 확인했습니다. 모든 외부 앱에서의 동작을 보장하지 않습니다.

## 소스 실행 및 EXE 빌드

Windows와 Python 3.14 x64를 사용합니다. 앱 실행 자체는 Python 표준 라이브러리만 사용합니다.

```powershell
python typer.py
```

빌드:

```powershell
./build.ps1
```

빌드 스크립트는 전용 `.venv-build` 환경에 `requirements-build.txt`의 빌드 의존성을 설치하고 `dist/UnicodeTyper.exe`를 생성합니다. 최초 빌드에는 의존성 다운로드를 위한 인터넷 연결이 필요합니다.

Release의 `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다. EXE에는 코드 서명이 없습니다. 저장소 공개 자체가 소스 재배포 또는 재라이선스 권한을 부여하지는 않습니다.
